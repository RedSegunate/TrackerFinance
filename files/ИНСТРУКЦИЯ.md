# Tracker Finance 2.0: инструкция по запуску

Интерфейсы хостингов иногда меняются, поэтому названия кнопок могут чуть отличаться. Если что-то не совпало, пришлите мне скриншот или текст ошибки.

## Шаг 1. Создайте бота в Telegram (2 минуты)
1. В Telegram найдите **@BotFather**, отправьте `/newbot`.
2. Придумайте имя и логин (логин должен заканчиваться на `bot`).
3. BotFather пришлёт **токен**. Сохраните его, это `BOT_TOKEN`.

## Шаг 2. Ключ Claude API — НЕ нужен
Бот работает без ИИ: категории определяет по встроенному словарю (вода → Продукты, такси → Транспорт и т.д.) и запоминает слова, которым вы его научите. Никаких дополнительных оплат, кроме хостинга.
Если когда-нибудь захотите умное распознавание (необычные фразы), можно подключить ключ с console.anthropic.com: раскомментируйте строку `anthropic` в `requirements.txt` и добавьте переменную `ANTHROPIC_API_KEY`.

## Шаг 3. Загрузите код на GitHub
1. Создайте аккаунт на **github.com** и новый репозиторий (**New repository**, можно Private).
2. Загрузите из корня проекта `main.py`, `requirements.txt`, `Procfile` и весь каталог `webapp/` с файлами `index.html` и `app.js`, сохранив структуру папок.
   Не загружайте только `files/main.py`: это старая копия, в ней нет Mini App 2.0.
3. Нажмите **Commit changes**.

## Шаг 4. Подключите Supabase
1. Откройте проект Supabase → **Connect** → выберите **Session pooler** и скопируйте PostgreSQL URI. Нужен URI базы, а не `SUPABASE_ANON_KEY` или `SUPABASE_SERVICE_ROLE_KEY`.
2. URI содержит пароль базы данных. Добавьте его только в Render как `DATABASE_URL`; не отправляйте в чат и не коммитьте в GitHub.
3. Приложение автоматически создаст отдельную схему `tracker_finance` и таблицы при старте. Старые таблицы в `public` останутся нетронутыми.
4. Если в локальном `finance.db` уже есть записи, перед деплоем добавьте `DATABASE_URL` в локальный `.env`, выполните из корня проекта `py scripts/migrate_sqlite_to_supabase.py` и проверьте количества. Чтобы скопировать данные, повторите с `--apply`. Скрипт сохраняет ID и пропускает уже существующие строки.

## Шаг 5. Разверните на Render
1. Войдите на **render.com** через GitHub и выберите **New → Web Service**.
2. Подключите репозиторий `RedSegunate/TrackerFinance`, ветку `master`; **Root Directory** оставьте пустым.
3. Укажите команды:
   - Build: `pip install -r requirements.txt`
   - Start: `python main.py`
4. В **Environment** добавьте:
   - `BOT_TOKEN` = токен из шага 1
   - `ALLOWED_USERS` = ваш Telegram ID
   - `DATABASE_URL` = URI Session pooler из шага 4
   - `DB_SCHEMA` = `tracker_finance`
   - `TIMEZONE` = ваш часовой пояс
   - `ANTHROPIC_API_KEY` = необязательно, если нужен разбор через Claude
5. Создайте Web Service. Render выдаст HTTPS-домен вида `https://имя-сервиса.onrender.com`.
6. Добавьте `PUBLIC_URL` с этим адресом без завершающего слэша. После перезапуска откройте бота и отправьте `/start`.
7. Отдельный Render Disk не нужен: данные хранятся в Supabase. На тарифах с автоматическим сном бот может временно переставать обрабатывать сообщения; проверьте ограничения выбранного тарифа.

## Шаг 5. Проверьте бота
1. Откройте вашего бота в Telegram, нажмите **Start**.
2. Напишите `вода 50`. Бот ответит: «Расход: −50 ₽ · Продукты · вода».
3. Проверьте меню: «Мои финансы», «Добавить», «История», «Статистика», «Цели», «Бюджеты», «Настройки».
4. Нажмите «Мои финансы» или отправьте `/app`, чтобы открыть Mini App. Если кнопки приложения нет, проверьте `PUBLIC_URL` и HTTPS-домен Railway, затем перезапустите сервис и отправьте `/start`.
5. Отправьте `/token`. Бот пришлёт **адрес** и **ключ** для iPhone.

## Mini App 2.0
- Главная показывает накопительный баланс, месячные доходы и расходы, последние операции, бюджеты и цели.
- В «Аналитике» доступны периоды день, неделя, месяц и год, график расходов, категории и наблюдения по данным пользователя.
- В «Истории» можно искать, фильтровать, изменять и удалять операции; удаление можно отменить сразу после действия.
- Бюджеты и цели создаются и изменяются в приложении. Пополнения целей учитываются вручную и не меняют баланс операций.
- Настройки профиля включают тему, часовой пояс, уведомления о бюджетах и необязательную сводку по понедельникам.
- Валюта текущей версии — рубли. При заданном `DATABASE_URL` постоянные данные хранятся в Supabase PostgreSQL; без него локальная разработка использует SQLite. Данные из прежней SQLite-базы автоматически не копируются.

## Шаг 7. Команда на iPhone (голосовой ввод на кнопку действия)
1. Откройте приложение **«Команды» (Shortcuts)** → **+** (новая команда).
2. Добавьте действие **«Диктовать текст»** (Dictate Text). Язык: русский.
3. Добавьте действие **«Получить содержимое URL»** (Get Contents of URL):
   - URL: адрес из `/token` (например `https://имя-сервиса.onrender.com/api/add`)
   - Метод: **POST**
   - Тело запроса: **JSON**, добавьте два поля типа «Текст»:
     - `token` = ключ из `/token`
     - `text` = переменная **«Продиктованный текст»** (Dictated Text)
4. Добавьте действие **«Показать уведомление»** (Show Notification) или «Показать результат», чтобы увидеть ответ.
5. Назовите команду, например «Трата».
6. **Настройки → Кнопка действия → Команда** и выберите «Трата». Теперь нажимаете кнопку, говорите «покупка воды 50 рублей», и запись появляется в боте.

Кнопка действия есть на iPhone 15 Pro и новее. На остальных моделях команду можно вывести на экран «Домой», в виджет или запускать фразой «Привет, Siri, Трата».

## Команды бота
| Команда | Что делает |
|---|---|
| `вода 50`, `такси 350 и кофе 200`, `зарплата 80000` | запись расходов и доходов |
| `/today`, `/week`, `/month` | статистика |
| `/last`, `/del ID`, `/undo` | последние записи, удаление |
| `/budget Продукты 20000` | месячный лимит на категорию (0 убирает лимит) |
| `/budgets` | состояние лимитов |
| `/categories` | список категорий |
| `/cat ID Категория` | исправить категорию записи, бот запомнит слово |
| `/rules`, `/unrule слово` | что бот выучил, забыть слово |
| `/export` | выгрузка в Excel |
| `/token` | адрес и ключ для iPhone |

Бот предупредит, когда расходы по категории дойдут до 80% лимита и когда лимит будет превышен.

## Важно
- **Безопасность.** Никому не показывайте токен бота, API-ключ и ключ из `/token`. Если ключ утёк, скажите мне, добавлю его замену.
- **Ограничить доступ только вами.** Узнайте свой Telegram ID (бот @userinfobot) и добавьте переменную `ALLOWED_USERS` = ваш ID. Тогда посторонние не смогут пользоваться вашим ботом и тратить ваш баланс API.
- **Если категория выбрана неверно или «Другое»:** отправьте `/cat ID Категория` (номер записи виден в ответе бота и в `/last`). Бот исправит запись и запомнит слово, и в следующий раз определит категорию сам.
- **Ограничения режима без ИИ:** сумму нужно писать цифрами («5к», «5 000», «2.5к»), а не словами («пять тысяч»). Нестандартные слова бот сначала отнесёт к «Другое», пока вы его не научите.
